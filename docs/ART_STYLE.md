# MORI Cat Rescue 2D — Art Style

## Direction
Cozy 2D top-down / 3/4.

Keywords:
warm, soft, rounded, pastel, readable, chibi, calm.

## Runtime Art
Use PNG/WebP/sprite sheets.

Start with placeholders.

Final art may be:
1. hand-drawn 2D
or
2. Blender prerendered 3D -> transparent PNG

## Depth
Use Y sorting and foreground layers.

## Minimum Cat Animation
- idle
- walk
- sit
- loaf
- sleep
- eat
- play
- groom

Reuse animation sets and recolor/pattern variants.

## Palette
cream, warm wood, dusty pink, sage, soft blue, terracotta, off-white, warm brown.

## Blender Later
If used:
- fixed orthographic camera
- fixed render angle
- transparent background
- consistent world scale
- shared lighting
- batch render
